# Lost items
Платформа для потерянных и найденных вещей в учебных заведениях России

## Стек технологий
* **Язык и платформа:** C# / .NET 8
* **Интерфейс:** Avalonia UI
* **База данных:** Entity Framework Core + MS SQL Server
