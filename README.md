# Losty
Платформа для потерянных и найденных вещей в учебных заведениях России

## Стек технологий
* **Язык и платформа:** C# / .NET 8
* **Интерфейс:** Avalonia UI
* **База данных:** Entity Framework Core + MS SQL Server

## Как запустить проект локально
### 1. Подготовка среды
1. Установите **Visual Studio 2022-2026**
2. В Visual Studio установите расширение **Avalonia for Visual Studio**, после чего перезапустите IDE
3. Убедитесь, что установлен локальный сервер баз данных, а также **SSMS** при необходимости просмотра таблиц

### 2. Клонирование репозитория в Visual Studio
1. Откройте Visual Studio и на стартовом экране нажмите **Клоинрование репозитория**
